## 🎤 RECORDING TIPS

### **For Voiceover:**
- Use a quiet room with minimal echo
- Speak clearly at moderate pace
- Record in one take, edit later
- Use phone's voice memo app or Audacity (free)

### **For Screen Recording:**
- Use OBS Studio (free) for desktop
- Use phone's built-in screen recorder for mobile
- Record in 1080p minimum
- Keep cursor movements smooth

### **For Live Action:**
- Use tripod for stable shots
- Natural lighting is best
- Record multiple takes
- Keep background clean
