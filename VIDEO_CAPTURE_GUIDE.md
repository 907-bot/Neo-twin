## 🎯 THE 5-STEP CAPTURE PROCESS

### **STEP 1: Start at Corner**
```
┌─────────────────────────────────┐
│                                 │
│  📍 START HERE                  │
│  ↓                              │
│  Hold phone at eye level        │
│  Keep steady                    │
│  Press record                   │
│                                 │
└─────────────────────────────────┘
```

**Duration:** 5 seconds
**Tip:** Take a breath, steady your hands, then start recording

---

### **STEP 2: Walk in Circle**
```
    TOP-DOWN VIEW OF ROOM
    
    ┌──────────────────────────┐
    │                          │
    │   ┌──────────────────┐   │
    │   │                  │   │
    │   │    FURNITURE     │   │
    │   │                  │   │
    │   └──────────────────┘   │
    │                          │
    │  → → → → → → → → → →    │
    │  ↑                    ↓  │
    │  ↑   WALK THIS WAY    ↓  │
    │  ↑                    ↓  │
    │  ← ← ← ← ← ← ← ← ← ←    │
    │                          │
    └──────────────────────────┘
    
    Complete full 360° circle
    Walk at normal pace (2-3 min)
```

**Duration:** 60-90 seconds
**Tip:** Imagine you're painting the room with your camera

---

### **STEP 3: Tilt Up & Down**
```
    CEILING VIEW          EYE LEVEL           FLOOR VIEW
    ┌─────────┐          ┌─────────┐          ┌─────────┐
    │    ↑    │          │    →    │          │    ↓    │
    │  ╱   ╲  │          │         │          │         │
    │ │     │ │          │  ROOM   │          │  FLOOR  │
    │  ╲   ╱  │          │  VIEW   │          │  VIEW   │
    │    ●    │          │         │          │         │
    └─────────┘          └─────────┘          └─────────┘
    
    Capture all three angles for complete 3D understanding
```

**Duration:** 30 seconds
**Tip:** Spend 10 seconds on each angle

---

### **STEP 4: Get Close to Objects**
```
    FAR AWAY (BAD)          CLOSE UP (GOOD)
    ┌─────────────┐         ┌─────────────┐
    │             │         │             │
    │    [chair]  │         │   CHAIR     │
    │             │         │   DETAILS   │
    │             │         │             │
    │  Too small  │         │   Clear!    │
    │  in frame   │         │             │
    └─────────────┘         └─────────────┘
    
    Move closer to important objects
    Capture from 2-3 different angles
```

**Duration:** 30-60 seconds
**Tip:** Get within 1-2 meters of important objects

---

### **STEP 5: Complete the Circle**
```
    ┌──────────────────────────┐
    │                          │
    │   FINISH HERE 📍         │
    │   ↑                      │
    │   └── Should match       │
    │       starting position  │
    │                          │
    │  Stop recording here     │
    │                          │
    └──────────────────────────┘
    
    Return to where you started
    Ensures full 360° coverage
```

**Duration:** 5 seconds
**Tip:** Stop recording once you're back at start

## ✅ DO's and DON'Ts

### **✓ DO:**
```
┌─────────────────────────────────────────┐
│ ✓ Walk slowly and steadily              │
│ ✓ Capture from multiple heights         │
│ ✓ Get close to important objects        │
│ ✓ Shoot in good lighting                │
│ ✓ Complete full 360° circles            │
│ ✓ Keep phone at eye level mostly        │
│ ✓ Overlap views by 70%+                 │
│ ✓ Record for 2-5 minutes                │
└─────────────────────────────────────────┘
```

### **✗ DON'T:**
```
┌─────────────────────────────────────────┐
│ ✗ Run or move too fast                  │
│ ✗ Stand still and rotate                │
│ ✗ Point only at blank walls             │
│ ✗ Use digital zoom                      │
│ ✗ Shoot in very dark areas              │
│ ✗ Shake the camera                      │
│ ✗ Record for less than 30 seconds       │
│ ✗ Use flash photography                 │
└─────────────────────────────────────────┘
```

## 📊 VIDEO QUALITY CHECKLIST

Before uploading, verify your video:

```
QUALITY CHECKLIST:
┌─────────────────────────────────────────┐
│ □ Duration: 30 seconds - 10 minutes     │
│ □ Resolution: 720p minimum (1080p ideal)│
│ □ Frame rate: 24fps minimum (30+ ideal) │
│ □ Lighting: Well-lit, no dark areas     │
│ □ Stability: Minimal camera shake       │
│ □ Coverage: Full 360° of space          │
│ □ File size: Under 500MB                │
│ □ Format: MP4, MOV, or AVI              │
└─────────────────────────────────────────┘

If all boxes checked → Upload to NeoTwin!
```

## 📱 PHONE SETTINGS

### **iPhone:**
```
Settings → Camera → Record Video
→ Select: 4K at 30 fps (or 1080p at 30 fps)
→ Turn ON: Grid (for composition)
→ Turn OFF: HDR Video (causes issues)
```

### **Android:**
```
Camera App → Settings → Video Quality
→ Select: 4K at 30 fps (or 1080p at 30 fps)
→ Turn ON: Grid lines
→ Turn OFF: Auto HDR
→ Turn OFF: Stabilization (if available)
```

## ⏱️ TIMING GUIDE

| Room Size | Recommended Duration | Frames Extracted |
|-----------|----------------------|------------------|
| Small bedroom | 2 minutes | ~120 frames |
| Living room | 3 minutes | ~180 frames |
| Large room | 4 minutes | ~240 frames |
| Multiple rooms | 5-10 minutes | ~300-600 frames |
| Outdoor space | 5-10 minutes | ~300-600 frames |

**Frame extraction rate:** 2 frames per second (default)

## 🔍 QUALITY INDICATORS

### **Your video is GOOD if:**
- ✅ You can clearly see all objects
- ✅ No motion blur when walking
- ✅ Consistent lighting throughout
- ✅ All walls, floor, ceiling captured
- ✅ Video feels "smooth" when watching

### **Your video needs improvement if:**
- ❌ Dark or overexposed areas
- ❌ Shaky or blurry footage
- ❌ Missing angles (only eye-level)
- ❌ Too fast (under 30 seconds)
- ❌ Standing still and rotating

## 📞 NEED HELP?

If your reconstruction fails:

1. **Check video quality** using checklist above
2. **Re-record** following the 5 steps
3. **Ensure good lighting** — most common issue
4. **Walk slower** — second most common issue
5. **Contact support** if problem persists
